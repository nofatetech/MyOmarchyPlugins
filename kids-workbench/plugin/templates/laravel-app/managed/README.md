# .kids-workbench (managed)

Do not edit. This folder is replaced when the standards are updated
(`.kids-workbench/scripts/update.sh`, or the update button in the Kids Workbench sidebar).

- `standards/`: architecture, conventions, guardrails, testing, naming
- `AGENTS.base.md`: instructions for the agent, imported by the project's `AGENTS.md`
- `SYNC.md`: how to migrate after an update
- `guards/`: tests that protect the standards
- `scripts/`: `test.sh`, `doctor.sh`, `update.sh`
- `STATE.json`: which versions this project is on
