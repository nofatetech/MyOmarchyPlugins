# Mentors

A mentor is a person with a relationship to a kid or project, not an admin role. The supervisor role (usually a parent) still exists, but it is practical and real-life usable, not "because they're kids".

## Who
Parent, grandparent who's a retired mechanic, neighbor with a woodshop, friend's dad, makerspace member, online maker.
Each mentor attaches to a project or skill, not the whole machine.

## Features
- Lightweight connection: share a project link (read-only by default), get photo updates, leave a comment or "try this next" note. No account juggling.
- "Ask a mentor" button: sends a photo and a question to a chosen person.
- Mentor weekly digest: "here's what Lena built", with option to reply.
- Skill-to-mentor matching; can start as a plain text list ("Opa: cars, wood").
- Mentors can vouch for skills in the skills map (see [real-world.md](real-world.md)).
- Remote helper view via bench camera (later).

## Principle
The kid chooses what to share and with whom. See [principles.md](principles.md).
