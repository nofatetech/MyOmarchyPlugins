# Features (all ideas so far)

## Home and navigation
- Home screen offers "start something", not an app list.
- Big-tile launcher: Make a game, Draw, Write, Explore, My stuff.
- Bigger permanent sidebar with one-click shortcuts and a "New..." button.
- Easy access to get/create everything.
- Gentler window mode than default Hyprland tiling: floating by default, visible dock or taskbar.
- Bigger UI scale, fonts and click targets.
- First-run tour: "here's what you can do".
- Age tiers or per-kid profiles with a level toggle (unlocks terminal, full Godot editor, etc.).

## Projects
- A project is a folder with notes, photos, files, to-do list, timeline.
- Examples: build a go-kart, treehouse lights, band concert, fix the car.
- Each project pulls in the right tools (CAD, Godot, recorder, serial monitor).
- Progress is logged automatically, including photos.
- Templates: Godot starter game, HTML starter with live preview, comic page, Arduino, 3D print, record a song.
- Bite-sized challenges ("make an LED blink", "record a 4-bar loop", "print a keychain"); each can unlock the next tool.
- Bill of materials / parts and shopping list per project.
- Weekly prompt: "what do I want to learn?"

## My Creations hub
- One place for everything they make: drawings, games, docs, recordings, prints.
- One-click run or play.
- Optional publish: local server, private family gallery, print.
- Family gallery and "show mom/dad" button.
- Sharing with siblings and friends (shared folder, Syncthing or local Git behind a simple UI).

## Link saver (del.icio.us idea)
- Browser extension plus local app.
- Save, tag, add a note, browse as a gallery.
- Explore and analyze saved links.
- Attach saved links (repair video, guide) to a project.
- Later: turn a collection into a mini-site or zine.

## Everyday apps
- Browser, document editor, drawing (Krita, Pinta).
- Code editor, Godot, Tiled, pixel art tools.
- Webapps: Scratch, Piskel, itch.io, Excalidraw.

## Creating (digital)
- Games: HTML, Godot.
- Drawing and pixel art, comics.
- Writing, documents.
- Music: DAW (Ardour, LMMS), simple recorder.
- Video: OBS, simple editing.
- Visuals reacting to audio (Godot, shaders, VJ tools).

## Creating (physical)
- CAD: Tinkercad-style for younger, FreeCAD or OpenSCAD for older.
- 3D printing: slicer presets, OctoPrint/Klipper, "printed it!" log.
- Later: laser cutter, vinyl cutter, CNC.
- Electronics: KiCad for older kids, simple circuit simulator for younger.
- Soldering: visual guides, good vs bad joint photos, component lookup.
- Woodworking: cut-list optimizer, fraction-aware unit converter, plans from CAD, parts list.
- Cars: OBD-II reader, code lookup in plain language, maintenance log, torque specs.

## Step mode (hands-busy)
- Instructions one step at a time, large font, a photo per step.
- Voice control offline (Vosk or whisper.cpp): "next step", "zoom in", "start a 10-minute timer".
- Big-button or foot-pedal remote.
- Camera on the bench: quick photo log, time-lapse of builds, later a "show a remote helper" view.
- Timers.

## Knowledge base
- Offline copies of manuals, how-tos, saved videos, forum threads.
- Searchable, mixed with the kid's own notes and photos.
- Service manuals per car, tool manuals per machine.

## Logging and reflection
- Photo-first project log; kid doesn't have to type.
- Build log or video export, shareable.
- Daily log (optional), monthly family review.
- Auto-snapshots (btrfs/snapper), "undo my whole day".

## Time and balance
- Weekly rhythm: make / move / rest / share.
- Nudges tied to the current project and to physical activity.
- Event mode / show mode for concerts and demos: no notifications, full screen, routes audio and lights.

## AI (undecided)
- Options: none; "how do I do X" helper; coding buddy.
