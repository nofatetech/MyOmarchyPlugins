# Safety and guardrails

Stay on the trust side. Guardrails and guides for extremes; advisory otherwise. See [principles.md](principles.md).

## Digital
- Separate user account, no sudo for kid users.
- Auto-snapshots and backups; "undo my whole day".
- Hard stop on irreversible actions (delete project with no backup).
- Internet: open vs filtered vs curated is undecided (DNS filtering like NextDNS/AdGuard is an option). Values call, see open questions.
- No hidden surveillance.

## Physical
Short, 10-second checklists by activity and age, shown in step mode. Risky steps get an "ask a grown-up / mentor first" flag.

- **Cars:** jack stands, battery disconnect, hot exhaust, ECU flashing warning. Strongest guardrails here.
- **Woodwork:** per-tool pre-use checklist (table saw, router, drill press); some tools need an adult in the room.
- **Soldering:** ventilation or fume extraction, hot-iron habits, lead-free solder, eye protection.
- **3D printer:** heat, fire watch, never leave unattended for long.
- **Mains-voltage electronics:** hard guardrail.
