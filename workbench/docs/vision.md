# Vision

## Who
- Kids about 8 to 16, mixed ages (needs age tiers or per-kid levels).
- Starting with our own kids; we know we are experimenting.

## What
A laptop setup, built on Omarchy, that helps kids:
- use useful apps: browser, documents, drawing
- create games (HTML, Godot)
- explore, save and analyze links (think del.icio.us)
- express themselves, with a strong focus on **creating**
- make real-life things with the computer at their side

## Not just a keyboard
Computer does not mean sitting at the keyboard. The laptop can be:
- in the garage or workshop while they build
- connected to a go-kart
- in a tree house
- hooked up to music interfaces, cameras, DMX lights (do a concert)
- paired with Makey Makey, CAD, 3D printing, and more

## Time
Not hard time limits on the computer being on. Instead, help manage time:
- some for exercise-style activity
- some for creating
- some for real-life making
- some time off the computer

## Shape of the thing
Probably mostly configuration and curation on top of Omarchy, plus one or two small custom apps:
1. Separate user account and curated app set
2. Custom launcher menu and bigger sidebar with easy access to get/create
3. Link-saving tool (browser extension plus local app)
4. Project hub / "My Creations"
5. Device detection and setup (plug in anything, it works)
6. Step mode for hands-busy work
