# Roadmap (suggested)

## v0: config only
- Kid user account(s), curated apps and webapps.
- Bigger UI scale, floating-friendly window rules.
- Auto-snapshots.

## v1: smallest meaningful loop
- Project folder structure and templates (plain files).
- Home screen / launcher with big tiles and "start something".
- Link saver (extension plus local app), attachable to projects.
- Photo log for projects.
- Step-mode viewer for one project type (suggest: a first 3D print or a soldering kit).

## v2: devices and mentors
- Device detection and setup (Arduino, MIDI/audio, camera, printer).
- Mentor sharing: read-only project links, "ask a mentor", weekly digest.
- Offline knowledge base.
- Voice control for step mode.

## v3: real world
- Portfolio export, skills map with mentor vouching.
- Internship / contacts list and templates.
- Commission tracker.
- Show mode (concerts: DMX, OBS, audio routing).
- Car (OBD-II) and woodworking (cut list) tool sets.

## Always
- Monthly family review of what works.
- Keep plain-text config editable.
